# UI sound assets

`ui-click.wav` (Click_01) and `ui-open.wav` (Confirm_03) are from the
**Interface Bleeps** pack by **Bleeoop**: https://bleeoop.itch.io/interface-bleeps

License (per the pack page): royalty-free; free to use in non-profit and commercial
projects. Reselling as assets or sample packs is not permitted — these files ship only
as embedded UI sounds of this application, which is within the license.

Selected 2026-07-19 by spectral match against the Fallout Pip-Boy UI reference profile
(body ~890Hz, ~30-50ms decay, bright attack crust). Runtime pitch offsets are applied
in code (frontend/js/util.js SFX) — the files are unmodified originals.
