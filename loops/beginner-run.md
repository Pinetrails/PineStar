# L4 · Beginner Run — protect the moat (every 4h, live app, own worktree)

The moat is "easier than Hermes for beginners." Every tick, BE a first-time user and report
where a newbie gets stuck. Sandbox law: no gating, full power from minute one — any grind/
unlock/permission-wall you meet is itself a P0 finding.

## Each tick
1. Fresh state: boot the app with a clean profile/save (dev-seed or wiped save dir — never
   touch Andrew's real save).
2. Play the zero-to-value path, honestly, at newbie speed:
   awakening/onboarding → interview → place a COMPUTER → summon an agent → give a REAL small
   task → watch it work → find the result → rate the work.
3. At every step ask: did the UI tell me what to do next without prior knowledge? Log every
   hesitation >10s, every misleading label, every dead-end click, every claim you couldn't
   verify happened (ties into truthful telemetry).
4. Rotate a secondary probe each tick: voice-in, a second agent, a skill install, a channel
   connect, a routine schedule — one per tick, first-timer's eyes.
5. Findings to qa/findings/ ranked P0 (blocks zero-to-value) / P1 (confusing) / P2 (rough).
   ≤30-line obvious fixes (label text, glow target, hint copy): fix in your lane, gate green,
   READY for L1. Never fix by adding a gate/tutorial-wall — that violates the sandbox law.

## Digest
`zero-to-value: PASS in <n> min / FAIL at <step>` + probe result + finding IDs.
