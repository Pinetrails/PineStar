# PS-2026-062 — Authoritative matched measurement evidence

## Purpose

Create the durable evidence contract required before Pine Star can truthfully call champion/challenger objective runs matched, without executing an experiment or weakening the existing recommendation gate.

## Changes

- Added a host-authorized immutable measurement store with stable measurement/cohort identity, arm, real role and configuration identity, matched task and conditions digest, objective/run outcome, completion evidence, runtime, provider/model cost and usage, retry/wasted-work facts, safety exceptions, uncertainty, and source references.
- Wired the store as the evidence source for champion/challenger evaluation without exposing a generic or public write endpoint.
- Strengthened complete-evidence qualification to require one authoritative measurement per objective and identical task IDs and condition digests across arms.
- Configuration labels supplied to the evaluation endpoint no longer establish configuration truth by themselves, and unrelated historical objectives cannot qualify as matched.

## Safety

- Only an in-process host authority can append measurement records; there is no public measurement mutation API.
- This change executes no objective or experiment and creates no scheduling, retry, autonomous-run, routing, or configuration-activation path.
- Records assert zero spending authority and no external visibility; existing E-stop, credential, cost, audit, publication, and activation boundaries remain unchanged.
- Test fixtures verify the contract only and are not operational measurement evidence.
