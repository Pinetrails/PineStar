# PS-2026-007 — Extensible Role Registry and Objective Router Foundation

**Date:** 2026-08-26
**Status:** Complete — foundation
**Type:** Phase 4 agent/objective architecture
**Git commit:** The commit containing this record

## Purpose

Establish an extensible Pine Star system-role registry and deterministic lowest-capable-level routing contract without hard-coding product behavior around one assistant personality or a closed roster.

## Implementation

- Added shared seed-role data spanning Operations, Development, and Research.
- Kept stable system role ID, display label, department, capabilities, model tier, escalation targets, permissions, and availability as separate fields.
- Added Economy/Balanced/Deep tier ordering without binding tiers to a provider or concrete model.
- Added deterministic objective routing that selects the lowest-tier active role satisfying every required capability.
- Enforced model-tier ceilings and explicit escalation when no role fits.
- Protected actions return `approval_required` before assignment.
- New roles and departments register without routing-logic changes.
- Seed Scout permissions explicitly prohibit automatic software installation.
