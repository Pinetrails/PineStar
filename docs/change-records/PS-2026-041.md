# PS-2026-041 — Pending Review Archival Guard

**Date:** 2026-09-03
**Status:** Complete

## Intent

Prevent a generic product status update from archiving a project while its protected publication review remains live and auditable.

## Implementation

- Refuse `approval_required → archived` in the product project store.
- Direct the lifecycle through protected publication-request withdrawal before ordinary archival can occur.
- Retain the existing guarded transitions for withdrawal, approval-required entry, and publication.

## Safety

- This change adds only a refusal guard; it does not mutate or settle the pending objective.
- The existing authenticated withdrawal path remains the sole way to cancel and audit the request.
- No approval grant, publication executor, marketplace write, account, credential, purchase, subscription, or spending authority was added.
