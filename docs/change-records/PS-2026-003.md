# PS-2026-003 — Release Asset Safety Foundation

**Date:** 2026-08-26
**Status:** Complete
**Type:** Read-only distribution safeguard
**Git commit:** The commit containing this record

## Purpose

Turn Pine Star's reference-art policy into an executable release check before original-art work begins.

## Implementation

- Added `npm run release:asset-safety`, a read-only scan of frontend, website, native icon, and installer asset roots.
- Block distribution when a text asset contains `REFERENCE / PLACEHOLDER — DO NOT DISTRIBUTE`.
- Block clearly marked reference/placeholder binary filenames without attempting binary decoding.
- Keep documentation and other non-distributable source roots out of the scan to avoid policy-text false positives.
- Preserve the existing StarNet compatibility and excluded-asset inventory; this gate does not claim those assets are releasable or delete them.

## Verification

- Script syntax and whitespace checks: **PASS**.

## Boundary

This is one required input to a future Pine Star release decision, not a complete distribution approval. Original replacements, licensing review, native identity, signing, updater ownership, and the existing branding inventory remain separate work.
