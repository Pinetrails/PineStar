# PS-2026-050 — Advisory Champion/Challenger Evaluation

**Date:** 2026-09-06
**Status:** Complete

## Intent

Begin Phase 7 with a reusable evidence-bound evaluation seam that can compare observed configuration cohorts without autonomously changing Pine Star's roles, routing, models, permissions, or active configuration.

## Results

- Added authenticated `POST /api/evolution/champion-challenger`.
- Requires different configuration IDs and disjoint, settled objective cohorts assigned to the same stable system role.
- Derives completion, evidenced-completion, failure, cancellation, measured cost, cost per completion, uncertain-mutation, and wasted-work proxies from existing objective and run history.
- Writes one immutable bounded shared report per stable evaluation ID and rejects changed facts on retry.
- Returns `challenger_recommended` only when the challenger is no worse on the compared proxies, strictly better on at least one, and neither cohort contains an uncertain mutation.

## Verification

- Focused champion/challenger unit coverage: 10 assertions.
- Real HTTP coverage confirms the new endpoint remains behind the existing API-token gate.
- Node syntax checks and `git diff --check` pass apart from existing line-ending notices.

## Safety boundaries

- Protected and unsettled objectives are rejected.
- Missing matched run evidence is reported instead of treated as zero cost.
- The result is advisory only: no role, routing, model, permission, admission, activation, retirement, execution, external action, or spending mutation exists.
- The Big Bite was not reopened or modified.
