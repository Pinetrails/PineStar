# PS-2026-018 — Digital-Product Project Records

**Date:** 2026-08-27  
**Status:** Complete

## Intent

Start the Phase 6 business layer with durable product records that coordinate real Pine Star objectives and reports without becoming another execution or project-management engine.

## Implementation

- Added a crash-safe `pine-star.product-projects.json` store separate from the existing blessed-filesystem-project store and its path-trust authority.
- Records carry stable ID, bounded product/customer/marketplace/asset/deliverable metadata, owner, lifecycle state, QA/listing/publication state, blockers, next action, evidence, timestamps, revision, and truthful financial fields.
- New records have `$0` spending authority. Estimated/actual cost and revenue remain `null` unless supplied as real non-negative numeric records; strings such as `UNKNOWN` are never converted into invented zeroes.
- Deterministic transitions cover idea, research, planning, production, QA, listing readiness, approval-required publication, published, and archived states. Listing readiness requires passed QA.
- The normal authenticated update API cannot enter `published`. The store reserves that transition for a future caller presenting legitimate protected approval; request fields cannot self-authorize it.
- Objective and shared-report links are validated against their existing durable stores. Project progress projects only bounded IDs, statuses, roles, report types, and timestamps rather than copying transcripts or payloads.
- Added authenticated create/list/filter/inspect/update/link APIs with idempotent stable-scope creation, conflicting identity rejection, optimistic revision checks, and idempotent links.
- Added a read-only Product Projects section to the existing Reports window.

## Safety

- No marketplace adapter, account action, publication, purchase, subscription, message, credential access, financial commitment, external write, execution engine, or new authority was introduced.
- Existing objectives, routing, admission, runtime, reports, audit, recurring work, and Away work remain the machinery that performs project work.
