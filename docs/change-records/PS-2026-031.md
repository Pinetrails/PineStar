# PS-2026-031 — Local Business Snapshot Export

**Date:** 2026-09-02
**Status:** Complete

## Intent

Let a user carry an inspectable, bounded business snapshot out of the Reports UI without adding external synchronization, a new data store, or authority over commerce.

## Implementation

- Added an explicit `EXPORT BUSINESS SNAPSHOT` control to Reports.
- Reused the already loaded authenticated product-project, commerce-record, and business-ledger responses.
- Added the versioned `pine-star.business-snapshot-export.v1` contract.
- Projected only allowlisted readiness, marketplace-reference, financial, and evidence fields with bounded row and list counts.
- Kept the existing local browser-download mechanism; export happens only after a user click.

## Safety

- The export declares `destination:null` and `externalWritePerformed:false`.
- Unknown input fields are dropped rather than copied; focused tests include credential-like fields and verify their omission.
- No transcript, private memory, raw runtime payload, credential, or arbitrary source object is exported.
- No upload, sync, marketplace link, publication, account creation, payment, refund, purchase, subscription, spending, approval, or automatic trigger was added.
- Existing authenticated APIs, approval boundaries, E-stop, cancellation, audit, and evidence requirements are unchanged.
