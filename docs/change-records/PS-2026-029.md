# PS-2026-029 — Read-Only Commerce & Ledger UI

**Date:** 2026-08-31
**Status:** Complete

## Intent

Make recorded marketplace observations and evidence-backed business totals inspectable in Reports without creating external navigation or payment, refund, purchase, publication, or edit controls.

## Implementation

- Added commerce observation cards with state, marketplace, project, external listing ID/reference, and evidence fields.
- Added a recorded all-time business summary for revenue, expenses, refunds, net, and entry count.
- Added bounded ledger entry cards with type, USD amount, occurrence time, source, optional project, and evidence.
- Added the existing authenticated business-ledger GET request to the Reports fetch group; commerce data reuses the request introduced for portfolio inspection.
- Missing or failed data uses the existing honest empty/unavailable states.

## Safety

- All dynamic values pass through existing HTML escaping.
- Listing URLs are rendered as text, never links.
- No button, form, click handler, external link, POST/PUT/PATCH/DELETE request, marketplace action, payment/refund/purchase action, publication, credential field, or spending authority was added.
- Summary copy says values are recorded observations and that action/edit capabilities are unavailable.
