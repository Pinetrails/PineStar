## Purpose

Provide an inspectable, user-initiated bridge from Pine Star shared reports to ordinary files without selecting, discovering, or modifying an external Obsidian vault.

## Implementation

- Added local JSON and Markdown export actions to the Reports window.
- Added versioned `pine-star.shared-report-export.v1` JSON envelopes.
- Export receipts explicitly state `destination: null` and `externalWritePerformed: false`.
- Markdown output is concise, human-readable, and escapes embedded HTML.
- Export contains only the already bounded shared-report projection; private operational memory remains inaccessible.
- Synchronized the generated website application mirror.
