# PS-2026-016 — Deterministic Morning Brief

**Date:** 2026-08-27  
**Status:** Complete

## Intent

Produce a useful concise Morning Brief from existing Pine Star operational truth without a model call, raw-event dump, or second reporting system.

## Implementation

- Added a pure deterministic aggregator over durable objectives, existing shared reports, and real run-store records.
- The bounded brief distinguishes in-period completions and failures from currently active work and the current approval backlog.
- Recent Open-Source Scout discoveries remain structured and bounded; `TEST` and `ADD` recommendations become suggested next actions for the named specialist owner.
- Settled Auditor exceptions are surfaced from bounded result/settlement fields. Raw transcripts are neither read nor persisted.
- Runtime cost appears only when numeric in-period run records exist. Missing cost data produces no cost claim.
- Evidence references link the brief to contributing objective, report, and run IDs.
- Added authenticated `POST /api/reports/morning-brief`. A stable report ID makes retry idempotent; omitted periods continue from the prior brief or use a bounded 24-hour first window.
- Reports are normalized and stored through the existing `pine-star.shared-report.v1` store and remain visible through the existing report API/UI.

## Safety

- No model/provider call, spending authority, approval mutation, runtime activation, external message, publication, credential access, or new scheduler was added.
- Existing API token and origin enforcement protects generation and inspection.
