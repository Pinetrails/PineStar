# PS-2026-037 — Evidence-Gated Publication Approval Request

**Date:** 2026-09-02
**Status:** Complete

## Intent

Package a listing-ready product for an explicit Commander publication decision without granting or implementing publication authority.

## Implementation

- Added authenticated `POST /api/product-projects/publication-approval-request`.
- Requires a stable request ID, listing-ready/QA-passed project, internal listing draft, target marketplace, and linked product QA report covering every expected deliverable.
- Creates an idempotent shared request report and a protected `publish` objective.
- The protected objective is unassigned with `approval_required` status under the existing router.
- Links the request objective/report back to the product and moves it to `approval_required` through a private store option.
- Generic product updates can no longer enter `approval_required`, closing the previous bypass around this evidence package.
- Stable request IDs reject changed scope.

## Safety

- The response explicitly reports `externalAction:false`, `publicationPerformed:false`, and `spendingAuthorityUsd:0`.
- There is no approval grant, protected-objective admission, publication executor, marketplace write, account creation, credential handling, purchase, subscription, or spend.
- Existing authentication, independent QA, artifact provenance, E-stop, cancellation, audit, and protected routing remain authoritative.
