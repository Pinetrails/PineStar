# PS-2026-055 — Evaluation design lessons

## Purpose

Retain structured, immutable lessons from inconclusive and retain-champion evaluations so later experiment design can avoid repeating known evidence gaps or losing configurations.

## Changes

- Added bounded `evaluationLessons` to normalized shared reports.
- Champion/challenger reports now identify small cohorts, missing measured runs, missing completion evidence, uncertain mutations, and challenger proxy dimensions that lost to the retained champion.
- Each lesson names the affected arm and configuration, observed limitation, proxy dimension, and a bounded future-design instruction.
- Existing immutable report identity now includes the lesson projection.
