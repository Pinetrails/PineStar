# StarNet v0.10.4

This update makes the station more physical, expressive, and dependable while preserving truthful harness state.

- Station props received a broad visual overhaul with stronger local colour, clearer silhouettes, corrected workstation seating, improved arcade and studio proportions, and new left- and right-facing recliners.
- Agents now respect personal space, walls block conversations and social reactions, conveyor watching is naturally bounded, and walkable gaps between rooms correctly reveal space instead of an alley-like floor slab.
- Idle station life is richer: agents speak through animated glyph bubbles, gather when left alone, and gravitate toward companions they have actually worked with based on durable run history.
- COMMS speaker names now read as quiet callsigns, and message copy controls no longer cover timestamps.
- Telegram connections recover more reliably and retain keychain-backed configuration when agent identity settings are synchronized.
- Successful but unproductive tool loops are detected before they churn indefinitely, while repeated action capabilities remain available when they are still making progress.
- Browser downloads now return a verified saved-file receipt only after Chromium reports completion and the host confirms the file on disk.
