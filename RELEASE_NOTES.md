# StarNet v0.3.1

Multi-agent deliverables reach you now.

- **Worker outputs surface in COMMS.** When a delegated crew member saves a file or
  generates an image, the deliverable card (with image preview and click-to-open) now
  appears live in the chat, a notification fires, and the floor's crate/work counters
  credit it — previously the event died inside the delegation layer and the file was
  invisible.
- **No more "ghost files."** The overseer now receives a proven artifact list from each
  worker (what was saved, in whose workspace) and knows worker files live in the worker's
  own private workspace — so it can answer "where is it?" truthfully instead of checking
  its own folder, finding nothing, and offering to regenerate work that exists.
- Includes everything from v0.3.0 (cross-provider delegation, run-stream keep-alive,
  persisted diagnostics, worker-sprite truth, headless research, real version in
  diagnostics).
