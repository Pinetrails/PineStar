STARNET DOCS

// everything you need to run your station

StarNet is a local-first desktop harness: you create AI agents, organize them into a living pixel-art station, and the station's layout is the workflow they run. These docs cover installing it, connecting a model provider, and using every major system.

GETTING STARTED

Install on Windows, macOS, or Linux, get past the first-run OS warnings, and run your first agent.
PROVIDERS & KEYS

Bring your own OpenRouter key, sign in with OAuth, and store service keys your agents can use.
THE STATION

Rooms, hallways, and placed objects — how the layout you draw becomes real capability boundaries.
AGENTS & TEAMS

Recruiting, agent classes, the dossier, and running many agents concurrently.
AUTONOMY & NIGHT SHIFT

Let the station keep working while you're away — on a leash you define, with honest reporting.
SKILLS, RECIPES, ROUTINES

The how, the what, and the when of repeatable agent work.
CONNECTORS & INTEROP

MCP connectors, messaging channels, schedules, and using StarNet alongside other harnesses.
FROM OPENCLAW / HERMES

Concept map for migrating users — and how to keep your existing harness in the loop.
TROUBLESHOOTING

Install warnings, updater behavior, Linux libraries, uninstalling, and where to get help.
Docs philosophy: StarNet's core law is truthful telemetry — the app never claims state the harness can't prove. These docs follow the same rule. If something here doesn't match what you see in the app, that's a bug in one of them: tell us at androo.agi@gmail.com.
